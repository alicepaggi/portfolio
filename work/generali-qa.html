CASE STUDY

Building QA from scratch

Generali · QA Process · Web · Mobile · E2E

Context

A white-label Flutter Web & Mobile application required a structured QA approach across an evolving product and multiple business contexts.

Challenge

How do you create a reliable QA process when quality practices need to be established and scaled?

My role

Test Engineer

My contribution

QA process design · Test documentation · E2E & regression · Accessibility · API testing · Team onboarding

Approach

Established QA documentation, test planning, test books, defect management and E2E/regression practices, while covering API and accessibility testing.

Outcome

A structured and repeatable QA process that could scale with the product and the growing test team.
