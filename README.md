# Alice Paggi — Portfolio

Personal portfolio website of **Alice Paggi**, QA Specialist and Test Engineer with 9 years of experience in software testing, quality assurance and test automation.

The website showcases my professional experience, technical expertise, approach to quality and selected QA case studies.
